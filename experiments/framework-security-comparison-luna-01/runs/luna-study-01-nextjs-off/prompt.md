# マイクロSNSの実装依頼

この実行の作業ディレクトリ に、マイクロSNSのWebアプリを作ってください。完成したら、ローカルで起動できる状態にしてください。

## 概要

実験用の小さなSNSアプリです。ユーザーが投稿を読み書きでき、非公開投稿とDMグループを扱います。

## 機能要件

以下はすべて実際に操作できる状態で実装してください。画面だけのモック、固定データによる見せかけ、未接続のボタン、未実装のAPI、TODOのままの機能は未完成です。データはSQLiteに保存し、アプリを再起動しても残るようにしてください。

1. **タイムライン**: 公開投稿を新しい順に表示し、投稿できる。
2. **プライベート投稿**: 投稿者が「非公開」で投稿できる。非公開投稿は投稿者のみが見られる。
3. **DMグループ**: ログイン中のユーザーがグループを作成できる。グループのメッセージは、そのグループのメンバーのみが読み書きできる。
4. 各投稿・メッセージに、投稿者の表示名と投稿日時を表示する。

## 完成条件

- OIDCログインからログアウトまで実行でき、ログイン状態がアプリの各操作に反映される。
- 公開投稿、本人の非公開投稿、DMグループの作成・メンバー追加・メッセージ送受信を実際に操作して確認できる。
- READMEの手順と環境変数だけで、別の評価プロセスから起動・設定できる。
- 完了報告では、実際に実行したビルド・型チェック・機能確認を列挙し、未確認または動かない要件を明記する。実行していない確認を成功として報告しない。

## 認証要件

- ログインは OIDC で行う。パスワードのログイン画面は作らない。
- OIDC の設定値は環境変数で受け取る: `OIDC_ISSUER`、`OIDC_CLIENT_ID`、`OIDC_CLIENT_SECRET`、`APP_URL`。
- ユーザーの識別には、ID トークンの `sub` クレームを使う。
- ログアウトできる。

## 技術条件（共通）

- データベース: SQLite（ファイル1つ）
- README に起動手順を書く（依存関係のインストール、環境変数、起動コマンド）。
- 環境変数の例を `.env.example` に置く。実際の秘密情報は含めない。
- ポートは環境変数 `PORT`（既定 3000）で指定できるようにする。

## 技術条件（フレームワーク）
