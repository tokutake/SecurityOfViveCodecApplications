# SNS-01 クイックスタートガイド

## 前置条件

Claude Codeの設定で以下を有効にしてください：

```json
{
  "sandbox": {
    "network": {
      "allowLocalBinding": true
    }
  }
}
```

## ステップ1: 初期管理者作成

```bash
node init.js
```

対話的にユーザー名とパスワードを入力してください。
例：
- ユーザー名: `admin`
- パスワード: `admin123`

## ステップ2: サーバー起動

```bash
node server.js
```

以下のメッセージが表示されれば成功です：
```
Server running at http://localhost:3000
Mock OpenRouter API listening on port 3001
```

## ステップ3: ブラウザアクセス

ブラウザで以下にアクセス：
```
http://localhost:3000
```

## テスト手順

### 1. 管理者でログイン
- ユーザー名: `admin`
- パスワード: `admin123`

### 2. 一般ユーザー作成
- 「登録」タブから新しいユーザーを作成
- 例：ユーザー名 `user1`, パスワード `user123`

### 3. 一般ユーザーでログイン
- 作成したユーザーでログイン

### 4. OpenRouter APIキー設定
- サイドバーの「OpenRouter API」セクションで、適当なキー（例：`sk-test-key-123`）を入力
- 「設定」ボタンをクリック
- 「ステータス: 登録済み」と表示されることを確認

### 5. LLMアカウント作成
- サイドバーの「LLMアカウント」セクションで「新規作成」
- 以下を入力：
  - 表示名: `テストLLM`
  - モデル: `test/model-a`
  - 指示文: `短い投稿を生成してください`
- 「作成」をクリック

### 6. 人間の投稿作成
- タイムラインの「新規投稿」をクリック
- テキストを入力（例：「これは人間の投稿です」）
- 「投稿する」をクリック
- タイムラインに表示されることを確認

### 7. LLM投稿生成
- タイムラインでLLMアカウント名の横に「投稿生成」ボタンが表示される
- クリックして投稿を生成
- LLMの投稿が「LLM」バッジと共にタイムラインに表示されることを確認

### 8. 投稿削除
- 自分の投稿の「削除」ボタンをクリック
- タイムラインから削除されることを確認

### 9. 管理者でログイン
- 管理者ユーザーでログインし直す
- ユーザー管理画面で一般ユーザーを表示
- 別のユーザーの投稿も削除できることを確認

### 10. ユーザー停止
- 管理者の「ユーザー管理」から一般ユーザーを「停止」
- その後、そのユーザーでログインして投稿を作成しようとする
- 「Account suspended」エラーが表示されることを確認

## ファイル構成

```
├── init.js                # 初期管理者作成スクリプト
├── test.js                # テストスイート
├── data.db                # SQLiteデータベース（自動作成）
├── package.json           # Node.js設定
├── README.md              # 詳細ドキュメント
├── QUICK_START.md         # このファイル
└── public/
    ├── index.html         # HTML UI
    ├── style.css          # スタイルシート
    └── script.js          # ブラウザJavaScript
```

## トラブルシューティング

### サーバーが起動しない場合

1. ローカルポートバインディング設定を確認
2. ポート3000/3001が既に使用されていないか確認
3. `sandbox.network.allowLocalBinding: true` が設定されているか確認

### データベース削除したい場合

```bash
rm data.db
```

次回起動時に新規作成されます。

### テストのみ実行したい場合

```bash
node test.js
```

ブラウザなしでコア機能のテストができます。
