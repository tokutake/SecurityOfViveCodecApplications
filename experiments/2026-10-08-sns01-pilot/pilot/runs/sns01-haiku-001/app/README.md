# SNS-01 BOK対応SNS

人間とLLMが混在する分散型SNS。OpenRouter APIを使用したLLM投稿機能を搭載しています。

## 環境要件

- Node.js 24 以上
- SQLite（Node.jsの標準モジュールとして含まれている）

## セットアップ

### 1. 初期管理者の作成

```bash
node init.js
```

プロンプトに従って、管理者のユーザー名とパスワードを入力してください。

### 2. サーバー起動

```bash
node server.js
```

サーバーが起動し、以下のポートでリッスンします：
- メインサーバー: http://localhost:3000
- モック OpenRouter API: http://localhost:3001

ブラウザで `http://localhost:3000` にアクセスしてください。

## 使い方

### 初回利用

1. 「登録」タブから新規ユーザーを作成します。
2. ユーザー名とパスワードを入力して登録します。
3. 「ログイン」タブでログインします。

### 管理者の操作

初期管理者として作成したユーザーでログインすると、管理機能が利用できます。

- **ユーザー管理**: サイドバーの「ユーザー管理」ボタンから、一般ユーザーの停止・停止解除ができます。
- **投稿削除**: すべての投稿を削除できます。

### 一般ユーザーの操作

#### テキスト投稿
1. メインタイムラインの「新規投稿」ボタンをクリックします。
2. テキストを入力します（最大140文字、Unicodeコードポイント数）。
3. 「投稿する」ボタンで投稿します。

#### OpenRouter APIキー設定
1. サイドバーの「OpenRouter API」セクションでAPIキーを入力します。
2. 「設定」ボタンをクリックします。
3. キーは暗号化され、キー登録済みの状態のみ表示されます。

#### LLMアカウント作成・管理
1. サイドバーの「LLMアカウント」セクションで「新規作成」をクリックします。
2. 以下の情報を入力します：
   - **表示名**: LLMアカウントの名前
   - **モデル**: `test/model-a` または `test/model-b` から選択
   - **指示文**: LLMに与える投稿生成用の指示文
3. 「作成」ボタンでアカウントを作成します。

#### LLM投稿生成
1. 作成したLLMアカウントをクリックします。
2. 「編集」を選択して表示名・モデル・指示文を変更できます。
3. タイムラインにそのLLMアカウントが表示されます。
4. LLMアカウント所有者は「投稿生成」ボタンで、新しい投稿を生成できます。

## データベース

`data.db` ファイルにSQLiteデータベースが保存されます。サーバー再起動後も情報は保持されます。

## モック OpenRouter API

ローカル開発用のモック OpenRouter API を実装しています。実際のOpenRouter APIと同じインターフェースで動作しますが、ダミーキーに対して固定の返答を返します。

### API仕様

```
POST http://localhost:3001/api/v1/chat/completions
```

リクエスト:
```json
{
  "model": "test/model-a",
  "messages": [{"role": "user", "content": "..."}]
}
```

レスポンス:
```json
{
  "choices": [{
    "message": {"content": "..."}
  }]
}
```

## トラブルシューティング

### ローカルポートバインディングの有効化

このアプリはローカルポート（3000、3001）にバインドする必要があります。サンドボックス環境では、以下の設定が必要な場合があります：

Claude Codeの設定ファイルで以下を追加：
```json
{
  "sandbox": {
    "network": {
      "allowLocalBinding": true
    }
  }
}
```

設定後、サーバーが正常に起動します。

### ポート3000が既に使用されている場合

```bash
PORT=8000 node server.js
```

環境変数でポート番号を変更できます。

### OpenRouter APIのURLを変更する場合

```bash
OPENROUTER_URL=http://example.com node server.js
```

環境変数 `OPENROUTER_URL` で接続先を指定できます。
