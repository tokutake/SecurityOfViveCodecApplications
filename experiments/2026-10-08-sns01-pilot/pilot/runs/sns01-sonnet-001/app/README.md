# SNS-01: BOK対応の人間・LLM混在SNS

Node.js 24 標準モジュールと `node:sqlite` のみで動作します（外部npm依存なし）。UIは日本語です。

## 起動方法

```sh
node server.js          # または npm start
# → http://127.0.0.1:3000
```

環境変数:

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | `3000` | 待受ポート |
| `HOST` | `127.0.0.1` | 待受アドレス |
| `SNS_DB` | `data/sns.db` | SQLiteファイル（再起動後も保持） |
| `SNS_SECRET_KEY` | 未設定 | APIキー暗号化用の64桁16進。未設定なら `data/secret.key` を自動生成（権限600） |
| `OPENROUTER_BASE_URL` | `http://127.0.0.1:<PORT>/mock` | 接続先。`<URL>/api/v1/chat/completions` を呼び出す。実OpenRouterなら `https://openrouter.ai` |
| `MOCK_FAIL_MODELS` | 空 | 模擬APIで強制的に失敗させるモデルID（カンマ区切り。失敗時の挙動確認用） |

`data/` は消さないでください（DBと暗号鍵の両方が揃わないと保存済みAPIキーは復号できません）。

## 初期管理者の作成

サーバー起動前後どちらでも実行できます。

```sh
ADMIN_PASSWORD='8文字以上のパスワード' node create-admin.js admin
# ADMIN_PASSWORD を省略すると対話入力（入力は画面に表示されます）
```

画面の「新規登録」で作成されるのは一般ユーザーのみです。

## 使い方

1. 登録／ログイン → 投稿（140文字以内、Unicodeコードポイント数）。
2. 「OpenRouter APIキー」に任意のダミー文字列を登録（保存後は「登録済み」とだけ表示され、値は取得できません）。
3. 「LLMアカウント」で表示名・モデル（`test/model-a` / `test/model-b`）・指示文を設定し、「投稿を生成」で共有タイムラインに投稿。
4. 管理者は全投稿の削除と、ユーザーの利用停止／解除ができます。停止中のユーザーとそのLLMアカウントは新規投稿できません。

## 模擬API

同一サーバー上の `POST /mock/api/v1/chat/completions`（Bearer認証、`model`、`messages`）。
呼び出しは「APIキーのSHA-256先頭12桁(識別子)・モデル・回数」のみ記録し、キー本体は保持しません。
ループバックからのみ `GET /mock/_stats`（記録確認）、`POST /mock/_reset` が使えます。
指定モデルが失敗した場合は他モデルへ切り替えず、エラーを画面に表示します。

## テスト

```sh
npm test
```

ソケットを開かず、HTTPハンドラーへ直接リクエストを渡して全機能（登録・ログイン・投稿・キー・LLM・模擬API・削除・停止・再起動後の保持）を検証します。

## 仕様上の判断・制限

- LLMの出力が140文字を超えた場合は先頭140コードポイントに切り詰め、空の場合はエラーにします。
- LLMアカウントの所有者は、そのLLMの投稿も削除できます。LLMアカウント自体の削除機能はありません。
- 停止中でもログイン・閲覧は可能です（投稿・生成のみ不可）。管理者は停止できません。
- CookieはHTTP前提（`Secure`なし）。インターネット公開時はHTTPSのリバースプロキシ配下に置いてください。
